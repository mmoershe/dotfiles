# KDE Plasma Settings

## Caps Lock as additional Escape

1. `System Settings` -> `Keyboard` -> `Keyboard` -> `Key Bindings`
2. Check `Configure keyboard options`
3. Check `Caps Lock behavior` -> `Make Caps Lock an additional Esc`

## Global Desktop Wallpaper

For some reason, the `right-click on desktop` -> `Desktop and Wallpaper` menu only sets a wallpaper for one monitor/screen.
To set a wallpaper for all monitors/screens, go to `System Settings` -> `Wallpaper` and select `Set for all screens`.

## Weird 'Session Restore'

KDE Plasma automatically restores sessions on login by default.
Turn it off by checking `System Settings` -> `Session` -> `Desktop Session` -> `Start with empty session`.
